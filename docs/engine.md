# 运算规则与实施边界

## 路径与时间

运输资源是有向边，节点是具体仓库／货站／城市覆盖点。算法不自动把反向线路视为可用，不自动合并同城不同节点。

有城市覆盖点时仅从这些点出发／结束；未维护时增加虚拟城市覆盖点与待补全接驳，避免从机场直接出发而省略提货。中间同城节点无直接资源时，可显示缺失接驳段。每条路径最多 8 段，最多 2 个缺失接驳段，不允许节点循环。最多搜索 20,000 个状态、输出 300 个候选。达到上限明确提示，排序与推荐仅针对已找到的子集，不承诺全网络全局最优。

每段在上一段到达后加入本段处理时间，再寻找能够赶上截货的班期。班期按 IANA 时区及星期维护，实际运输耗时以小时计。夏令时按时区规则换算；不存在的当地时刻跳过，重复时刻采用确定的一个换算值，尚不支持同一当地时刻分别录入两个班次。线路有效期按起运节点当地出发日期校验，运价及汇率同样按该日期选取。

按需发运线路可按就绪时间出发；未维护时刻的非按需线路仅展示框架，发运与送达时间待确认。缺失接驳或未知时刻会向下游传播衔接不确定性，界面与导出隐藏不可确认的发运、到达及晚到承诺，展示已知段参考运输耗时（不含未知接驳与等待）。

机场航线的时刻独立于父航线，以时刻表采用的 IANA 时区保存四项钟点及跨日偏移，撤轮至挡轮用于运输衔接，起飞与落地分别保留。起止机场仍各有自身当地时区。周期班期按星期与有效日期执行；同航班指定日期规则优先于周期规则，包括指定日期取消。归档时刻不参与计算；存在已维护规则但没有可衔接的有效班次时排除该线路。每种活动班期可产生独立候选，保存时保留选定的子记录 ID 与内容快照，重新校验不会默默换为另一班次。

没有子时刻的航线可保留框架；未知截货、计划状态、未知航线经营有效期或承运条件均提示待确认，不参与完整推荐。系统不读取实时舱位和运力库存，仍需供应商确认。原有线路内嵌的每周班期兼容读取，不自动迁移其业务含义。

## 货物及装载

逐件校验长宽高和重量，并按件数合计整票重量、体积校验已维护上限。长宽高按输入方向比较，不自动旋转。堆叠与直立属性记录并保留在需求快照中；本期不做三维装箱、车辆装载优化、轴荷计算、吊装验算或大件道路勘察。不能把参数筛选等同实际可装载或可通行证明。

特殊属性逐项判断 yes / no / unknown；no 排除，unknown 待确认。对危险品还校验已填写的类别／UN 白名单。白名单为空表示无额外限定，不代表已取得监管或承运许可；缺危险品详情则待确认。

## 计价

- 总重量：每组单件重量 × 件数后求和。
- 总体积：长 × 宽 × 高 × 件数 / 1,000,000，单位 m³。
- 计费重：总实重与总体积 × 1,000,000 / 体积重除数取大；当前按整票总量比较，不是逐件取大后求和。
- 数量按运价指定的 rounding 向上进位。
- 阶梯：从小到大找首个覆盖数量上限的档位，以该档单价计算全部数量；超过全部阶梯用基础单价。不是累进分段计价，也不是按起始重量的阶梯。
- 基础运费 = max(进位数量 × 单价, 最低基础运费)。
- 固定附加费按票；百分比附加费以基础运费为基数，不复利。最低收费仅作用于基础运费。
- 金额使用十进制运算，原币费用按分四舍五入，分段人民币折算按分取整后求和。
- 多个有效运价选可计算人民币费用最低者；缺汇率的报价不挤掉可折算报价。
- 外币汇率选生效日期最近、覆盖出发日期的一条。同日期多条时按资源 ID 的确定顺序取首条，建议避免重叠。
- 车数、柜数及箱型由业务人员提供，不自动推测。

每条运价中涉及不同币种的附加费应先换算成该运价币种再维护。计价模型未覆盖的实际报价规则应先扩展规则，不得强行套入错误公式。

「完整费用」指当前运输段的已维护费用，并非保证税费及所有供应链费用齐备。服务未包含或待确认时，方案待确认，不给完整推荐标签。界面展示已计运输段费用，同时提示另行确认服务。

## 推荐

资料完整、无待确认项的候选参与推荐；城市级地址调整提示不单独使候选失去资料完整状态。有按时到达候选时优先从这些候选中推荐，否则从已知条件可行的晚到候选中推荐并显示晚到时间。

折中方案将费用和耗时分别在本次合格候选中作 min-max 标准化，两项各 50% 权重。多个标签可能落在同一方案。未知条件方案仍展示，不授予完整推荐标签。

## 保存和一致性

资源编辑带版本号，过时更新返回 409。批量导入全量校验并事务提交，关联缺失则整批回滚。引用中的供应商、机场、节点和线路不能删除。机场唯一三字码由写入事务校验，自动派生节点一并更新，不能直接在节点分类改写。飞行时刻每次新增或修改均保存到 flight_revisions；删除当前记录仍保留修订及已保存方案。已有历史的时刻 ID 不能重新用于新记录。

保存方案时由服务端重新校验路径并计算费用，不接受浏览器提供的总价。版本存储需求、结果及资源快照；导出只读该快照。保存新版本使用当前资源，旧版本不改写；并发版本保存发生冲突时要求刷新。

独立陆运查询已接入地图普通驾车距离及数据库缓存，详见 road-routing.md；不自动成为运输资源或承运证明。外部船期、运价订阅、自动订舱、实际货物合规判断等来源尚未接入。

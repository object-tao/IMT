# 一期需求基线 V1.0

来源：用户在本聊天确认的需求。状态：已确认并授权开发。

## 使用范围

公司内部使用，人员维护供应商、线路、班期和运价。资源可覆盖欧洲、美国等区域，不将国家和城市写死。不建设角色划分、部门权限及业务审批。

起运与目的地分别选择国家和城市；国家使用代码、城市使用全球地名库的稳定 ID，区分同名地点。内部保留仓库、机场、港口、站点等具体节点，以判断接驳完整性。支持出口、进口及不同供应商分段资源组合。城市覆盖范围计价在具体地址确认后可能调整。

## 需求与货物

最早可提货时间、可选最晚要求送达时间，多组货物：名称、包装、件数、单件长宽高、重量、可堆叠及保持直立。支持整箱、拼箱、散杂货、大件，以及危险品、带电、液体和温控属性；危险品可细分 UN 编号和类别，电池分内置、配套、纯电池。

整车及整柜计费时显式录入车辆数、箱数、箱型；系统不凭总体积自行认定实际装载数量。

## 方案及费用

自动拼接运输段；校验已维护承运条件、尺寸重量、班期、截货时间、处理时间和有效期。保留同路径的不同供应商组合；展示参考费用最低、时效最快及费用时效折中的候选。超期时仍展示并提示晚到。无方案时解释受限原因。

按公斤、计费重、立方、车、柜、票计价，支持最低收费、阶梯单价和固定／百分比附加费。保留原币金额，按内部维护汇率折算人民币。暂不建设销售加价及利润核算。

缺价、缺汇率、承运条件未知、缺失接驳均明确标记。资料不完整的方案不参与完整方案推荐；缺失接驳耗时不默认为实际零耗时，不得据此承诺交期。

报关、清关、装卸、仓储、保险等服务记录已包含／未包含／待确认及相关运价附加费，不办理实际业务。

## 陆运距离与时效（2026-10-22 确认）

通过左侧「方案工作台」下方的一级菜单「陆运距离与时效」，独立查询城市之间的推荐普通驾车公路路线、里程、地图驾车耗时、卡车参考驾驶耗时及单驾 / 双驾预计运输时效。国内优先使用高德普通路径规划，美国和欧洲使用 HERE 普通驾车。支持可修改的参考平均车速与驾驶窗口，装卸、等待和跨境通关等未知耗时标注未计入，轮渡和车辆摆渡列车默认关闭。支持可选出发时间用于到达时间测算，不承诺未来交通预测。无覆盖、无可用路线或 API 异常时明确说明，不用直线距离代替。普通路线使用相应 Web 服务 Key，无需开通货车版本；详见 [接入与验收规则](road-routing.md)。

## 机场与独立飞行时刻（2026-10-22 确认）

新增共享机场资料：中文名称、英文名称、IATA 三字码、国家、城市、当地时区和别名。供应商下有航线，航线下有可选的独立飞行时刻；没有时刻的航线仍可录入并作为待确认框架展示，不默认随到随发。

飞行时刻区分周期班期和指定执行日期，保留撤轮、起飞、落地、挡轮四项时间、各自跨日偏移、机型、机号、截货、来源、状态与修订历史。表内时区和机场当地时区分别保存，已提供的时刻表使用 2026 年及北京时间。支持 XLSX / CSV 预览、机场与航线复用、去重、冲突提示和整批事务导入。指定日期优先于同航班周期规则，取消的日期例外使对应日停班。未知条件不自动补成承运承诺，资源变更不改写历史方案快照。

## 保存及输出

陆运查询成功后持久保存路线结果；相同城市、方向及摆渡条件下优先读取数据库，不重复调用 API。运输时效按本次参数重新计算，明确显示数据取得日期和历史路线提示。

可手工调整运输路径与供应商，重新计算，保存不可变方案版本及完整资源快照。内部版包含供应商及内部备注；客户版隐藏这些内容。支持真实 Word 文件及打印页面另存 PDF。

## 二期

订舱、派车、实际运输执行与跟踪，实际报关清关，财务和利润核算，角色权限，以及供应商外部系统接入，均不包含在本期。

## 待真实资料验收

已收到供应商航空时刻截图，按确认的年份、时区核对导入；未提供的运价、截货与承运规则保持待确认。虚构示例与自动化测试用于功能验证，不能替代真实运价、班期及特殊货物承运规则的业务签认。服务器、域名、部署区域、预算待定，未启动正式对外服务。

# 全球国家与城市库

新增起运国家、目的国家及全球城市选择。国家是地名身份的一部分；同名城市还通过稳定 GeoNames ID 区分。

## 数据范围和来源

当前快照包含 **252 个国家／地区和 5,232,157 条城市及居民点记录**，其中 248 个国家／地区具有居民点数据。国家／地区目录沿用 GeoNames countryInfo；部分无人居住地区本身没有城市，不能编造填充。

数据来自 [GeoNames 全球全集](https://download.geonames.org/export/dump/)，使用 allCountries.zip 中全部 feature-class P 记录，不设置人口门槛。P 类包含城市、镇、村及其他居民点，也可能包含历史或局部居民点，并不等于全部都是具有法定城市地位的行政单位。GeoNames 不保证绝对完整、准确或实时；新增、合并及更名需要更新快照。

数据许可为 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，界面页脚和数据说明保留来源署名。国家中文标签使用 ICU / Unicode CLDR；城市保留数据源主名称，支持检索数据源提供的中文、英文、当地名称及别名。别名可能包含昵称，因此不会任意把别名当作正式城市名。

## 使用与身份

- 先选国家，再搜索并选择城市。候选显示行政区，区分同一国家的同名地点。
- 切换国家立即清空旧城市和其 ID，后端再次校验城市归属。
- 节点选择城市后带入其 IANA 时区；已有具体业务节点时间规则仍可维护。
- 可选择尚无运输资源的城市，但不会因此自动生成供应商或线路。
- 起止城市、城市覆盖点和同城缺失接驳均按国家及城市身份判断，不跨国家自动衔接。

## 本地安装与自动发布

地名库约 1.13 GB，独立于业务数据库，不存放在 C 盘。压缩快照约 401 MB，作为 GitHub Release 资源分发，不把二进制数据库提交到 Git 历史。

```powershell
npm run geo:sync
```

安装脚本读取 `assets/geography/manifest.json`，下载固定版本，校验 SHA-256、gzip 和元数据后再安装。已有相同快照时跳过下载。本地启动脚本先安装地名库；CI 和容器构建同样执行安装，容器内直接包含快照，运行时不依赖外部地名服务或付费 API。

可通过 GEO_DATABASE_FILE 指定另一个数据库路径。更新快照应先停服务，避免 Windows 对正在打开文件的替换限制。地名库可以重新安装，不替代业务数据备份。

## 旧数据兼容

启动迁移将已有节点的国家名称规范为代码，并在名称能唯一匹配时关联城市 ID。遇到歧义不会猜测，资源列表标记「城市归属待确认」，需要在节点编辑中选择正确城市。

历史方案版本不改写。读取缺少国家字段的旧方案时，从已保存运输段推导国家用于展示和导出；新版本仍按当前资源重新校验。

## 维护新快照

下载 GeoNames 的 allCountries.zip、countryInfo.txt、admin1CodesASCII.txt 至 D 盘工作目录，然后运行：

```powershell
npm run geo:build -- D:\CodexSessionArchive\IMT\work\geo-source
```

脚本流式解析，不将全球全集全部装入内存；建立国家索引与全文别名索引，输出数据库及 gzip 压缩包。发布新快照时更新 manifest 的版本 URL、校验值及元数据，再运行全球查询、同名城市、旧方案兼容和浏览器测试。
